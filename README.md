> **정보처리기사 실기(2020~2026년 기출 복원 + 언어특화 + 킬러 테마)** 수험생을 위한 실전형 주관식 CBT 웹 애플리케이션입니다.

## 🛠️ 핵심 기능

### 1. 주관식 단답형 & 코드 출력 유연 자동 채점 (Grader Engine)
- 실기 시험 특성에 맞춘 100% 주관식 채점 지원.
- 대소문자 무관/엄격 처리, 앞뒤 공백 및 다중 공백 자동 정규화.
- SQL 세미콜론(`;`), 따옴표(`"`, `'`), 괄호(`()`), 파이썬 리스트 대괄호(`[]`) 유연 비교.
- 숫자 정수/실수(`90` == `90.0`) 등가성 판정.
- 한글/영문 동의어(Aliases) 모두 정답 인정 (예: `싱글톤` / `Singleton` / `Singleton Pattern`).
- 다중 빈칸 문항 `(1)`, `(2)` 독립 채점 및 **부분 점수(Partial Credit, 🟡 세모 표기)** 완벽 반영.
- 코드 출력 결과(개행, 공백, 쉼표) 정규화 비교.

### 2. A4 연습지 1장 시뮬레이터 (시험장 실전 반영)
- 실제 시험장 수험생 1인당 1장만 배부되는 규정을 완벽 반영.
- **고해상도 1200×1697 A4 표준 버퍼**: 브라우저 창 크기를 조절하거나 줌인/줌아웃해도 드로잉이 지워지거나 깨지지 않고 영구 보존.
- **단일 탭 점 찍기(Dot tap)** 및 캔버스 밖으로 마우스가 나갔다 돌아와도 이어지는 **경계 밖 드로잉 추적(Window tracking)** 지원.
- **✏️ 펜 드로잉 모드**:
  - 검정(모나미 수험 펜), 파랑, 빨강 3색 지원.
  - 세필(1.5px), 보통(2.5px), 굵게(5.0px) 두께 조절.
  - 지우개(Eraser), 실행 취소(Undo ↩), 다시 실행(Redo ↪), 전체 삭제.
  - A4 배경 스타일: 무지 A4, 모눈 격자, 4분할 접기선, 줄노트.
- **📋 변수 추적표 (Trace Table) 모드**:
  - 루프 변수(i, j, sum, *p)의 변화를 표로 작성하여 실수 없이 디버깅.
  - 단순 루프, 이중 루프, 포인터 배열, 재귀 스택 템플릿 기본 제공.
  - 열/행 동적 추가(`+열 추가`, `+행 추가`) 및 삭제(`-열 삭제`, `-행 삭제`), 표 초기화 지원.
  - **[📋 A4 연습지로 가져오기]**: 문제 해설 카드의 루프 변수 추적표 헤더를 1클릭으로 내 연습지로 즉시 복사하여 연습 가능!

### 3. 실전 모드 vs 연습 모드 & 150분 타이머
- **실전 모드**: 150분(2시간 30분) 카운트다운 타이머 작동, 10분 미만 시 경고 점멸, 시험 종료 시 종합 채점.
- **연습 모드**: 문항별로 `[정답 확인]` 버튼을 눌러 즉시 채점하고 해설 및 변수 추적표를 바로 확인.

### 4. 60점 합격 판정 & 🔥 "틀린 문제만 다시 풀기 (오답 복습 모드)"
- 동적 배점 계산 (20문항 5점, 15문항 6.7점, 25문항 4점) 및 60점 이상 합격 판정.
- **틀린 문제만 다시 풀기**: 오답 문항만 필터링하여 답안을 초기화하고 즉시 재도전.
- 오답 재도전 채점 시 **오답 정복률(예: 3/3문항 정답, 100%)**을 별도 집계하여 정상 칭찬 피드백을 제공하며, 상단에 오답 복습 모드 배너 및 `[전체 회차로 복귀]` 버튼 제공.

### 5. 📑 실기 족보 1·2·3탄 & 벼락치기 꿀팁 모달
- 상단 헤더의 `[📑 실기 족보 & 꿀팁]` 버튼으로 언제든지 즉시 열람:
  - **족보 1탄**: GoF 디자인 패턴 23종 완벽 암기 공식, 결합도 7단계, 응집도 7단계, 테스트 기법.
  - **족보 2탄**: 정규화 1NF~5NF/BCNF 원부이결다조, 트랜잭션 ACID, SQL DDL/DML/DCL 및 윈도우 함수.
  - **족보 3탄**: 서브넷 마스크 CIDR 계산 비법, 암호화 알고리즘 완벽 분류, 네트워크 공격 기법.
  - **⚡ 3주 벼락치기 꿀팁**: 비전공자/직장인을 위한 과목별 점수 배분 포트폴리오(프로그래밍 35점 + SQL 15점 + 단답 20점 = 70점), A4 1장 4분할 활용법, 주관식 감점 방지 원칙.
