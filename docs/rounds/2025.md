```c
#include <stdio.h>

int fibo(int n) {

    return 0;
}
```

피보나치 수열 재귀함수입니다.

따라서 8이 출력됩니다.

> **[주의 포인트]**  
> fibo(0)=0, fibo(1)=1부터 시작하여 N번째 항의 값을 차례로 도출합니다.

**🔍 [변수 추적표 (Trace Table)]**

| --- | --- | --- |

| 1 | fibo(1) | 1 |
| 2 | fibo(1) + fibo(0) | 1 |
| 3 | fibo(2) + fibo(1) | 2 |
| 4 | fibo(3) + fibo(2) | 3 |

#### [2025_3 Q2] 다음 Java 프로그램의 실행 결과를 쓰시오.

**[문제 지문]**
다음 Java 프로그램의 실행 결과를 쓰시오.

```java
class Base {
    public void print() {
        System.out.print("Base ");
    }
}

class Derived extends Base {
    @Override
    public void print() {
        System.out.print("Derived ");
    }
    public void print(String msg) {
        System.out.print(msg + " ");
    }
}

public class Main {
    public static void main(String[] args) {
        Base b = new Derived();
        b.print();
        Derived d = (Derived) b;
        d.print("Hello");
    }
}
```

> **🔑 [모범 답안]**: `Derived Hello`
> *인정 유사 답안*: `Derived Hello `, `Derived, Hello`

**📖 [상세 해설]**
1. Base b = new Derived(): b.print()는 오버라이딩된 Derived의 print()가 호출되어 "Derived "를 출력합니다.
2. Derived d = (Derived) b: 다운캐스팅 후 오버로딩된 print("Hello")가 호출되어 "Hello "를 출력합니다.
3. 결과: "Derived Hello "

> **[주의 포인트]**  
> 다형성 오버라이딩 메서드 호출과 오버로딩 메서드의 차이를 이해해야 합니다.

**🔍 [변수 추적표 (Trace Table)]**
| 단계 | 호출 메서드 | 출력 |
| --- | --- | --- |
| 1 | b.print() (오버라이딩) | Derived  |
| 2 | d.print('Hello') (오버로딩) | Hello  |

**🔍 [변수 추적표 (Trace Table)]**

| i = 1 | 2 | 거짓 (2 > 4) | 4 |

```c
#include <stdio.h>

int main() {
    int sum = 0;
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= i; j++) {
            sum += 1;
        }
    }
    printf("%d", sum);
    return 0;
}
```

> **🔑 [모범 답안]**: `15`

**📖 [상세 해설]**

총 실행 횟수 = 1 + 2 + 3 + 4 + 5 = 15.
따라서 sum = 15입니다.

> **[주의 포인트]**  
> 1부터 n까지의 합 공식 n(n+1)/2 = 5 * 6 / 2 = 15와 동일합니다.

**🔍 [변수 추적표 (Trace Table)]**
| i 값 | j 반복 범위 | j 반복 횟수 | sum 누적 |
| --- | --- | --- | --- |
| i = 1 | j = 1 | 1회 | 1 |
| i = 2 | j = 1, 2 | 2회 | 3 |
| i = 3 | j = 1, 2, 3 | 3회 | 6 |
| i = 4 | j = 1..4 | 4회 | 10 |
| i = 5 | j = 1..5 | 5회 | 15 |

```c
#include <stdio.h>

int main() {

    printf("%d %d %d", a, b, c);

```

> *인정 유사 답안*: `7, 8, 8`, `7,8,8`

> **[주의 포인트]**
