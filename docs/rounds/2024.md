**[문제 지문]**
다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.

```c
#include <stdio.h>

int main() {
    int arr[5] = {5, 3, 8, 1, 2};
    int temp;
    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < 4 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
    printf("%d %d", arr[0], arr[4]);
    return 0;
}
```

> **🔑 [모범 답안]**: `1 8`
> *인정 유사 답안*: `1, 8`, `1,8`

**📖 [상세 해설]**
오름차순 버블 정렬(Bubble Sort) 알고리즘입니다.
정렬 완료 후 배열은 {1, 2, 3, 5, 8}이 됩니다.
arr[0]은 최솟값 1이고, arr[4]는 최댓값 8입니다.
출력: 1 8

> **[주의 포인트]**  
> 버블 정렬 후 최솟값과 최댓값을 순서대로 출력하는 문제입니다.

#### [2024_3 Q2] 다음 Java 프로그램의 실행 결과를 쓰시오.
- **출제**: 2024년 제3회 기출 복원 (문항 2) | **영역**: `Java` | **토픽**: `2.3 Java 객체지향 & 상속 / 다형성`

**[문제 지문]**
다음 Java 프로그램의 실행 결과를 쓰시오.

```java
public class Main {
    public static void main(String[] args) {
        int sum = 0;
        int i = 0;
        do {
            i++;
            sum += i;
        } while (i < 5);
        System.out.println(sum);
    }
}
```

> **🔑 [모범 답안]**: `15`

**📖 [상세 해설]**
do-while 문은 최소 1회 실행 후 조건을 검사합니다.
i는 1, 2, 3, 4, 5까지 증가하며 sum에 누적됩니다.
sum = 1 + 2 + 3 + 4 + 5 = 15.
i가 5일 때 (5 < 5)는 거짓이 되어 루프를 탈출합니다.
출력: 15

> **[주의 포인트]**  
> do-while 문 탈출 시점의 i값과 누적합 계산입니다.

**🔍 [변수 추적표 (Trace Table)]**
| 반복 | i 증가 | sum 누적 | 조건 검사 (i < 5) |
| --- | --- | --- | --- |
| 1회 | i = 1 | 1 | 1 < 5 (참) |
| 2회 | i = 2 | 3 | 2 < 5 (참) |
| 3회 | i = 3 | 6 | 3 < 5 (참) |
| 4회 | i = 4 | 10 | 4 < 5 (참) |
| 5회 | i = 5 | 15 | 5 < 5 (거짓, 종료) |

**[문제 지문]**

```java
public class Main {
    public static void main(String[] args) {
        int a = 5;
        int b = a++;
        int c = ++a;
        System.out.println(a + " " + b + " " + c);
    }
}
```

> **🔑 [모범 답안]**: `7 5 7`
> *인정 유사 답안*: `7, 5, 7`, `7,5,7`

> **[주의 포인트]**

| a = 5 | - | 5 |

| c = ++a | c = 7 | 7 |

#### [2024_3 Q13] 다음 Java 프로그램의 실행 결과를 쓰시오.
- **출제**: 2024년 제3회 기출 복원 (문항 13) | **영역**: `Java` | **토픽**: `2.3 Java 객체지향 & 상속 / 다형성`

**[문제 지문]**
다음 Java 프로그램의 실행 결과를 쓰시오.

```java
public class Main {
    public static void main(String[] args) {
        int a = 0;
        for (int i = 1; i <= 5; i++) {
            a += (i % 2 == 0) ? i : -i;
        }
        System.out.println(a);
    }
}
```

> **🔑 [모범 답안]**: `-3`

**📖 [상세 해설]**
i가 짝수이면 +i, 홀수이면 -i를 더합니다:
- i=1 (홀): -1
- i=2 (짝): +2 -> 1
- i=3 (홀): -3 -> -2
- i=4 (짝): +4 -> 2
- i=5 (홀): -5 -> -3
따라서 최종 a는 -3입니다.

> **[주의 포인트]**  
> 홀수는 음수로, 짝수는 양수로 교대 부호 합산입니다.

**🔍 [변수 추적표 (Trace Table)]**
