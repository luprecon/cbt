**[문제 지문]**
다음은 10진수 n(초깃값 10)을 2진수로 변환하여 8자리로 출력하는 Java 프로그램이다. 빈칸 (1), (2)에 들어갈 알맞은 조건식 또는 연산식을 쓰시오.

> **[지문/보기]**
> [출력 결과]
> 00001010

```java
class good {
    public static void main(String[] args) {
        int[] a = new int[8];
        int i = 0;
        int n = 10;
        while (   1   ) {
            a[i++] = (   2   );

```

    }

        if (num <= 1) return num;
        return compute(num - 1) + compute(num - 3);
    }
}

  - compute(3) = compute(2) + compute(0)

    - compute(2) = compute(1) + compute(-1)

      - compute(-1) = -1 (-1 <= 1)

> 전송 단위가 '비트(Bit)'인 계층은 1계층인 물리 계층입니다.

#### [2020_1 Q20] 다음 모듈 간 호출 관계 다이어그램을 분석하여, Fan-in(팬인) 개수가 2 이상인 모듈의 명칭을 모두 쓰시오.
- **출제**: 2020년 제1회 기출 복원 (문항 20) | **영역**: `소프트웨어공학` | **토픽**: `요구사항 분석 & UML`

**[문제 지문]**
다음 모듈 간 호출 관계 다이어그램을 분석하여, Fan-in(팬인) 개수가 2 이상인 모듈의 명칭을 모두 쓰시오.

> **[지문/보기]**
> ┌─── [ A ] ───┐
>        │      │      │
>        ▼      ▼      ▼
>      [ B ]  [ C ]  [ D ]
>       │ ╲    ╱ │     │
>       │  ╲  ╱  │     │
>       ▼   ▼▼   ▼     ▼
>      [ E ] [ F ] [ G ] [ J ]
>       │     │     │
>       └──┬──┘     ▼
>          ▼      [ I ]
>        [ H ]
> 
> ※ 모듈 호출(화살표) 관계:
> - A -> B, C, D
> - B -> E, F
> - C -> F, G
> - D -> J
> - E -> H
> - F -> H
> - G -> I

> **🔑 [모범 답안]**: `F, H`
> *인정 유사 답안*: `F,H`, `H, F`, `H,F`, `F H`, `H F`

**📖 [상세 해설]**
Fan-in(팬인)은 해당 모듈을 호출하는 상위 모듈의 수(해당 모듈로 들어오는 화살표 수)입니다.
- A: 0
- B, C, D: 1 (모두 A로부터)
- E: 1 (B로부터)
- F: 2 (B와 C로부터 -> Fan-in >= 2 만족)
- G: 1 (C로부터)
- J: 1 (D로부터)
- H: 2 (E와 F로부터 -> Fan-in >= 2 만족)
- I: 1 (G로부터)
따라서 Fan-in 수가 2 이상인 모듈은 F, H 입니다.

> **[주의 포인트]**  
> Fan-in은 들어오는 화살표(자신을 호출하는 모듈), Fan-out은 나가는 화살표(자신이 호출하는 모듈)입니다.
