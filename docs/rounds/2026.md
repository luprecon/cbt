#### [2026_1 Q1] 다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.
- **출제**: 2026년 제1회 기출 복원 (문항 1) | **영역**: `C` | **토픽**: `C언어 포인터 & 다차원 배열`

**[문제 지문]**
다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.

```c
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr + 1;
    int sum = 0;
    
    for (int i = 0; i < 3; i++) {
        sum += *(p + i);
    }
    printf("%d", sum);
    return 0;
}
```

> **🔑 [모범 답안]**: `90`

**📖 [상세 해설]**
arr 배열의 시작 주소에서 arr + 1은 arr[1]의 주소(&arr[1])를 가리킵니다.
p는 arr[1](20)을 가리키므로, 루프에서 i=0일 때 *(p+0) = 20, i=1일 때 *(p+1) = 30, i=2일 때 *(p+2) = 40이 됩니다.
따라서 sum = 20 + 30 + 40 = 90 입니다.

> ⚠️ **[단골 함정 (Trap Point)]**  
> p가 arr[0]이 아니라 arr+1(즉 arr[1]=20)부터 시작한다는 점을 놓치면 10+20+30=60으로 오답을 내기 쉽습니다.

**🔍 [변수 추적표 (Trace Table)]**
| 반복 (i) | 포인터 표현식 | 가리키는 값 | sum 누적 |
| --- | --- | --- | --- |
| 초기상태 | p = arr + 1 | arr[1] (20) | 0 |
| i = 0 | *(p + 0) | 20 | 20 |
| i = 1 | *(p + 1) | 30 | 50 |
| i = 2 | *(p + 2) | 40 | 90 |

#### [2026_1 Q2] 다음 Java 프로그램의 실행 결과를 쓰시오.
- **출제**: 2026년 제1회 기출 복원 (문항 2) | **영역**: `Java` | **토픽**: `Java 상속 & 부모 생성자`

**[문제 지문]**
다음 Java 프로그램의 실행 결과를 쓰시오.

```java
class Parent {
    int x = 10;
    Parent() {
        System.out.print("P");
    }
    void show() {
        System.out.print(x);
    }
}

class Child extends Parent {
    int x = 20;
    Child() {
        System.out.print("C");
    }
    void show() {
        System.out.print(x);
    }
}

public class Main {
    public static void main(String[] args) {
        Parent obj = new Child();
        obj.show();
    }
}
```

> **🔑 [모범 답안]**: `PC20`
> *인정 유사 답안*: `PC 20`

**📖 [상세 해설]**
1. new Child() 호출 시 부모 클래스 Parent의 생성자가 먼저 실행되어 'P'가 출력됩니다.
2. 이후 Child 생성자가 실행되어 'C'가 출력됩니다.
3. obj.show()는 부모 타입 Parent obj 참조 변수이지만, 자식 객체 Child에서 오버라이딩된 show() 메서드가 동적 바인딩(다형성)되어 호출됩니다.
4. 따라서 Child의 show()가 실행되어 Child의 인스턴스 변수 x인 20이 출력됩니다.
최종 출력: PC20

> ⚠️ **[단골 함정 (Trap Point)]**  
> 자바의 인스턴스 메서드는 동적 바인딩되므로 부모 타입 변수로 참조하더라도 자식의 오버라이딩 메서드가 실행됩니다. 또한 자식 생성자 호출 전 부모 생성자가 먼저 실행됩니다.

**🔍 [변수 추적표 (Trace Table)]**
| 실행 순서 | 실행 코드 | 출력 내용 | 누적 출력 |
| --- | --- | --- | --- |
| 1단계 | super() (Parent 생성자) | P | P |
| 2단계 | Child() 생성자 | C | PC |
| 3단계 | obj.show() (오버라이딩 메서드) | 20 | PC20 |

#### [2026_1 Q4] 다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.
- **출제**: 2026년 제1회 기출 복원 (문항 4) | **영역**: `C` | **토픽**: `C언어 포인터 & 다차원 배열`

**[문제 지문]**
다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.

```c
#include <stdio.h>

int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}

int main() {
    int res = f(4) + f(3);
    printf("%d", res);
    return 0;
}
```

> **🔑 [모범 답안]**: `30`

**📖 [상세 해설]**
f(n)은 팩토리얼(n!)을 계산하는 재귀함수입니다.
f(4) = 4 * 3 * 2 * 1 = 24
f(3) = 3 * 2 * 1 = 6
따라서 res = 24 + 6 = 30 입니다.

> ⚠️ **[단골 함정 (Trap Point)]**  
> 재귀함수 호출 시 종료 조건(n <= 1)에 도달할 때까지 스택 호출을 전개해야 합니다.

**🔍 [변수 추적표 (Trace Table)]**
| 함수 호출 | 전개 식 | 계산값 |
| --- | --- | --- |
| f(4) | 4 * f(3) = 4 * 6 | 24 |
| f(3) | 3 * f(2) = 3 * 2 | 6 |
| f(2) | 2 * f(1) = 2 * 1 | 2 |
| f(1) | 종료조건 (n<=1) | 1 |
| 합계 | f(4) + f(3) = 24 + 6 | 30 |

#### [2026_1 Q7] 다음 C언어 프로그램의 실행 결과를 쓰시오.

**[문제 지문]**
다음 C언어 프로그램의 실행 결과를 쓰시오.

```c
#include <stdio.h>

int main() {
    int a = 12; // 1100(2)
    int b = 10; // 1010(2)
    int c = a ^ b;
    int d = a & b;
    printf("%d %d", c, d);
    return 0;
}
```

> **🔑 [모범 답안]**: `6 8`
> *인정 유사 답안*: `6, 8`, `6,8`

**📖 [상세 해설]**
1. a = 12 = 1100(2), b = 10 = 1010(2)
2. XOR(^) 연산: 두 비트가 다르면 1, 같으면 0
   1100 ^ 1010 = 0110(2) = 6
3. AND(&) 연산: 두 비트 모두 1일 때만 1
   1100 & 1010 = 1000(2) = 8
출력 포맷: '%d %d'이므로 공백으로 구분하여 '6 8' 입니다.

> ⚠️ **[단골 함정 (Trap Point)]**  
> 출력 구분자가 쉼표가 아니라 공백 한 칸(%d %d)임에 유의해야 합니다.

**🔍 [변수 추적표 (Trace Table)]**

| --- | --- | --- |

| b | 1 0 1 0 | 10 |

#### [2026_1 Q8] IPv4 주소 192.168.1.0/26 대역을 서브넷팅하여 네트워크를 분할하였다. 이 때 각 서브넷에서 호스트에게 할당 가능한 최대 호스트(Host) 수를 쓰시오.

**[문제 지문]**
IPv4 주소 192.168.1.0/26 대역을 서브넷팅하여 네트워크를 분할하였다. 이 때 각 서브넷에서 호스트에게 할당 가능한 최대 호스트(Host) 수를 쓰시오.

> *인정 유사 답안*: `62개`

**📖 [상세 해설]**

#### [2026_1 Q10] 다음 Java 프로그램의 실행 결과를 쓰시오.
- **출제**: 2026년 제1회 기출 복원 (문항 10) | **영역**: `Java` | **토픽**: `Java static 공유 변수`

**[문제 지문]**
다음 Java 프로그램의 실행 결과를 쓰시오.

```java
class Counter {
    static int count = 0;
    int num = 0;
    
    void increment() {
        count++;
        num++;
    }
}

public class Main {
    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        c1.increment();
        c2.increment();
        System.out.println(c1.count + " " + c1.num);
    }
}
```

> **🔑 [모범 답안]**: `2 1`
> *인정 유사 답안*: `2, 1`, `2,1`

**📖 [상세 해설]**

- **출제**: 2026년 제2회 기출 예상/복원 (문항 1) | **영역**: `C` | **토픽**: `C언어 포인터 & 다차원 배열`

**[문제 지문]**
다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.

```c
#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main() {
    struct Point p1 = {10, 20};
    struct Point *ptr = &p1;
    ptr->x += 5;
    ptr->y *= 2;
    printf("%d, %d", p1.x, p1.y);
    return 0;
}
```

> **🔑 [모범 답안]**: `15, 40`
> *인정 유사 답안*: `15,40`, `15 40`

**📖 [상세 해설]**
ptr은 구조체 변수 p1의 메모리 주소를 가리키는 구조체 포인터입니다.
ptr->x는 p1.x를 의미하므로 p1.x = 10 + 5 = 15가 됩니다.
ptr->y는 p1.y를 의미하므로 p1.y = 20 * 2 = 40이 됩니다.
출력 형식: '%d, %d'이므로 '15, 40'이 출력됩니다.

> ⚠️ **[단골 함정 (Trap Point)]**  
> 구조체 포인터에서 멤버에 접근할 때 화살표 연산자(->)를 사용하는 문법과 원본 구조체 변수 p1의 값이 직접 변경된다는 점을 확인해야 합니다.

**🔍 [변수 추적표 (Trace Table)]**
| 연산 단계 | 실행 코드 | p1.x 값 | p1.y 값 |
| --- | --- | --- | --- |
| 초기화 | struct Point p1 = {10, 20} | 10 | 20 |
| 1단계 | ptr->x += 5 | 15 | 20 |
| 2단계 | ptr->y *= 2 | 15 | 40 |
| 출력 | printf('%d, %d', p1.x, p1.y) | 15 | 40 |

#### [2026_2 Q4] 다음 C언어 프로그램의 실행 결과를 쓰시오.
- **출제**: 2026년 제2회 기출 예상/복원 (문항 4) | **영역**: `C` | **토픽**: `C언어 포인터 & 다차원 배열`

**[문제 지문]**
다음 C언어 프로그램의 실행 결과를 쓰시오.

```c
#include <stdio.h>

int main() {
    int arr[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int *p = &arr[0][0];
    int sum = 0;
    
    for (int i = 0; i < 6; i++) {
        if (i % 2 == 1) {
            sum += *(p + i);
        }
    }
    printf("%d", sum);
    return 0;
}
```

> **🔑 [모범 답안]**: `12`

**📖 [상세 해설]**
2차원 배열은 메모리 상에 1차원으로 연속 배치됩니다: {1, 2, 3, 4, 5, 6}.
p는 시작 주소(&arr[0][0])를 가리키므로 *(p + i)는 각 원소를 순서대로 접근합니다.
i는 0부터 5까지 반복하며, i % 2 == 1인 홀수 인덱스는 i = 1, 3, 5 입니다.
- i = 1: *(p + 1) = 2
- i = 3: *(p + 3) = 4
- i = 5: *(p + 5) = 6
sum = 2 + 4 + 6 = 12 입니다.

> ⚠️ **[단골 함정 (Trap Point)]**  
> 2차원 배열의 메모리 행 우선(Row-major) 연속 배치 구조와 홀수 인덱스(1, 3, 5)에 위치한 값의 합산임을 파악해야 합니다.

**🔍 [변수 추적표 (Trace Table)]**
| 인덱스 i | 홀수 조건 | 원소 *(p + i) | sum 누적 |
| --- | --- | --- | --- |
| i = 0 | 거짓 | 1 | 0 |
| i = 1 | 참 | 2 | 2 |
| i = 2 | 거짓 | 3 | 2 |
| i = 3 | 참 | 4 | 6 |
| i = 4 | 거짓 | 5 | 6 |
| i = 5 | 참 | 6 | 12 |

#### [2026_2 Q10] 다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.
- **출제**: 2026년 제2회 기출 예상/복원 (문항 10) | **영역**: `C` | **토픽**: `C언어 포인터 & 다차원 배열`

**[문제 지문]**
다음 C언어로 작성된 프로그램의 실행 결과를 쓰시오.

```c
#include <stdio.h>

int main() {
    char str[] = "KOREA";
    char *p = str;
    while (*p != '\0') {
        p++;
    }
    printf("%d", (int)(p - str));
    return 0;
}
```

> **🔑 [모범 답안]**: `5`

**📖 [상세 해설]**
1. str[]은 'K', 'O', 'R', 'E', 'A', '\0'로 구성된 6바이트 문자열 배열입니다.
2. p가 '\0'(널 문자)를 만날 때까지 p++로 1바이트씩 이동합니다.
3. '\0'의 위치에서 멈췄을 때 p는 str + 5를 가리킵니다.
4. 포인터 간의 뺄셈 p - str은 두 포인터 사이의 요소 개수를 계산하므로 (str + 5) - str = 5가 됩니다 (즉, 문자열의 길이 strlen과 동일).

> ⚠️ **[단골 함정 (Trap Point)]**  
> 널 문자(\0) 직전까지 순회한 포인터의 차이는 문자열의 순수 길이(5)를 의미합니다.

**🔍 [변수 추적표 (Trace Table)]**
| 포인터 p | *p 문자 | 조건 (*p != '\0') | p - str |
| --- | --- | --- | --- |
| str + 0 | 'K' | 참 | 0 |
| str + 1 | 'O' | 참 | 1 |
| str + 2 | 'R' | 참 | 2 |
| str + 3 | 'E' | 참 | 3 |
| str + 4 | 'A' | 참 | 4 |
