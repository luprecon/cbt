#### [2021_3 Q1] 다음 Java 프로그램의 실행 결과를 쓰시오.
- **출제**: 2021년 제3회 기출 복원 (문항 1) | **영역**: `Java` | **토픽**: `Java 객체지향 프로그래밍`

**[문제 지문]**
다음 Java 프로그램의 실행 결과를 쓰시오.

```java
class Connection {
    private static Connection _inst = null;
    private int count = 0;

    static public Connection get() {
        if (_inst == null) {
            _inst = new Connection();
            return _inst;
        }
        return _inst;
    }

    public void count() { count++; }
    public int getCount() { return count; }
}

public class Main {
    public static void main(String[] args) {
        Connection conn1 = Connection.get();
        conn1.count();
        Connection conn2 = Connection.get();
        conn2.count();
        Connection conn3 = Connection.get();
        conn3.count();

        System.out.print(conn1.getCount());
    }
}
```

> **🔑 [모범 답안]**: `3`

**📖 [상세 해설]**
싱글톤(Singleton) 패턴 추적:
1. `Connection.get()`은 `_inst`가 null일 때 단 한 번만 새 인스턴스를 생성하고 이후에는 동일한 인스턴스를 반환합니다.
2. conn1, conn2, conn3는 모두 동일한 단 하나의 Connection 인스턴스를 가리킵니다.
3. count()가 3회 호출되어 단일 인스턴스의 count 변수가 0 -> 1 -> 2 -> 3으로 누적 증가합니다.
4. conn1.getCount()는 3을 반환하여 출력됩니다.

> ⚠️ **[단골 함정 (Trap Point)]**  
> 싱글톤 패턴이므로 객체가 3개 생성되는 것이 아니라 단 하나의 객체 공간을 공유하여 count가 3이 됩니다.

**[문제 지문]**
다음 Java 프로그램의 실행 결과를 쓰시오.

```java
public class Main {
    public static void main(String[] args) {
        int a = 3, b = 4, c = 3, d = 5;
        if ((a == 2 | a == c) & !(c > d) & (1 == b ^ c != d)) {
            a = b + c;
            if (7 == b ^ c != a) {
                System.out.println(a);
            } else {
                System.out.println(b);
            }
        } else {
            a = c + d;
            if (7 == c ^ d != a) {
                System.out.println(a);
            } else {
                System.out.println(d);
            }
        }
    }
}
```

> **🔑 [모범 답안]**: `7`

**📖 [상세 해설]**
조건문 논리 및 비트 연산 추적:
1. 첫 번째 if 조건 검사:
   - `(a == 2 | a == c)`: (false | true) = true
   - `!(c > d)`: !(3 > 5) = !(false) = true
   - `(1 == b ^ c != d)`: (false ^ true) = true (XOR: 서로 다르면 true)
   - true & true & true -> 조건문 참!
2. if 블록 내부 실행:
   - `a = b + c` = 4 + 3 = 7
   - 중첩 if: `(7 == b ^ c != a)`
     * 7 == 4 -> false
     * c != a -> 3 != 7 -> true
     * false ^ true = true
   - 중첩 if가 참이므로 `System.out.println(a);` 실행 -> 7 출력.

> ⚠️ **[단골 함정 (Trap Point)]**  
> XOR(^) 연산자는 두 피연산자의 참/거짓 값이 다를 때 true를 반환합니다.

**🔍 [변수 추적표 (Trace Table)]**
| 항목 | 평가 식 | 결과 |
| --- | --- | --- |
| 조건 1 | a == 2 | a == c | false | true -> true |
| 조건 2 | !(c > d) | !(3 > 5) -> true |
| 조건 3 | 1 == b ^ c != d | false ^ true -> true |
| 첫 if 결과 | true & true & true | true (if문 진입) |
| 변수 갱신 | a = b + c | a = 4 + 3 = 7 |
| 중첩 if | 7 == b ^ c != a | false ^ true -> true |
| 출력 | System.out.println(a) | 7 |

```java
        return x + y;
    }
}

    int sun(int x, int y) {
        return x - y + super.sun(x, y);
    }
}

public class Main {
    public static void main(String[] args) {
        Ovr1 a1 = new Ovr1();
        Ovr2 a2 = new Ovr2();
        System.out.println(a1.sun(3, 2) + a2.sun(3, 2));
    }
}
```

2. `a2.sun(3, 2)`: Ovr2의 오버라이딩된 sun 호출:
   - `3 - 2 + super.sun(3, 2)`
   - = 1 + (3 + 2) = 1 + 5 = 6

> a2.sun(3, 2)는 3 - 2 + (3 + 2) = 1 + 5 = 6이며, a1 결과 5와 합산하여 11이 됩니다.

- **출제**: 2021년 제1회 기출 복원 (문항 1) | **영역**: `네트워크` | **토픽**: `IPv4 서브넷 마스킹 계산`

**[문제 지문]**
물리적 MAC 주소를 기반으로 해당 장비의 논리적 IP 주소를 알아내기 위해 사용하는 역순 주소 결정 프로토콜의 영문 약어를 쓰시오.

> **🔑 [모범 답안]**: `RARP`
> *인정 유사 답안*: `rarp`, `Reverse Address Resolution Protocol`

**📖 [상세 해설]**

> ⚠️ **[단골 함정 (Trap Point)]**  
> IP -> MAC은 ARP이고, MAC -> IP 역방향은 RARP입니다.

#### [2021_1 Q6] 다음 [급여] 테이블에 대해 SQL 문을 실행한 결과(출력되는 카운트 숫자)를 쓰시오.
- **출제**: 2021년 제1회 기출 복원 (문항 6) | **영역**: `SQL` | **토픽**: `SQL 집계·조인·윈도우 함수`

**[문제 지문]**
다음 [급여] 테이블에 대해 SQL 문을 실행한 결과(출력되는 카운트 숫자)를 쓰시오.

> **[지문/보기]**
> [급여 테이블]
> | EMPNO | SAL |
> | --- | --- |
> | 100 | 1000 |
> | 200 | 3000 |
> | 300 | 1500 |
> 
> [쿼리]
> SELECT COUNT(*) FROM 급여
> WHERE EMPNO > 100 AND SAL >= 3000 OR EMPNO = 200;

> **🔑 [모범 답안]**: `1`

**📖 [상세 해설]**
SQL 연산자 우선순위: AND가 OR보다 높습니다.
1. `EMPNO > 100 AND SAL >= 3000` 평가:
   - 100행: EMPNO > 100 거짓
   - 200행: 200 > 100(참) AND 3000 >= 3000(참) -> 참
   - 300행: 300 > 100(참) AND 1500 >= 3000(거짓) -> 거짓
2. `OR EMPNO = 200` 평가:
   - 200행이 유일하게 참
따라서 조건을 만족하는 튜플은 200행 1개뿐이므로 COUNT(*) 결과는 1입니다.

> ⚠️ **[단골 함정 (Trap Point)]**  
> AND가 OR보다 우선 평가되며, 만족하는 행은 EMPNO=200인 단 1행입니다.
